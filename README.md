# Домашняя работа по уроку 10.1

## Описание: 
Домашняя работа представляет собой набор утилит для обработки банковских транзакций, включая фильтрацию, сортировку и маскировку конфиденциальных данных.

## Основные функции:

- Обработка дат (get_date.py)
- Маскировка данных (masks.py)
- Универсальная маскировка (widget.py)
- Обработка транзакций (processing.py)
- Сортировка списка по дате (sort_by_date.py)

## Тестирование

```
python -m tests.test_sort_by_date
python -m tests.test_processing
python -m tests.test_widget
```
